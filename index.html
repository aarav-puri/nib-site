Features

Built to make AP Classroom practice count.

One focused tool: retry the questions you already have without the answers staring back at you.

Hide the markers

Test yourself honestly

Covers the green and red correctness highlights and the answer explanations, so a completed assignment reads like a fresh one.

One switch

Toggle it anywhere

Turn hiding on or off from the Nib popup or the small floating panel on the page. Reveal the answers when you are ready to check.

Nothing leaves your browser

Private by design

No account, no API key, no network requests. Nib only runs on AP Classroom and only changes how the page looks.

Setup guide

Set up Nib in five minutes.

Nib is not yet on the Chrome Web Store, so it is installed manually. No coding experience required.

Install the extension

1

Download the folder

On the GitHub repository, select Code, then Download ZIP. Unzip it to a permanent location such as Documents. Moving the folder later disables the extension.

Or clone it with git:

git clone https://github.com/aarav-puri/nib
2

Open your extensions page

Enter the address for your browser:

Chrome  chrome://extensions
Edge    edge://extensions
Brave   brave://extensions
3

Turn on Developer mode

Enable the toggle in the top-right corner. This reveals the Load unpacked button.

4

Load unpacked

Select Load unpacked and choose the folder that directly contains manifest.json. ZIP downloads often include a nested folder; select the inner one.

5

Pin Nib to your toolbar

Open the extensions menu (puzzle icon) and pin Nib for quick access.

Usage

1

Open an assignment

Go to a graded AP Classroom assignment or progress check. Nib is active only on apclassroom.collegeboard.org.

2

Turn on Answer Hider

Open Nib and flip the Answer Hider switch. A small panel appears on the page with the same toggle.

3

Work through the set

Answer each question again with the markers covered, then switch hiding off to check yourself.

Limitations

  • Active only on apclassroom.collegeboard.org.
  • Hides markers on multiple-choice questions. Other question layouts may still show feedback.
  • If College Board changes the page, some markers may show until Nib is updated.
  • No sync. Nib keeps no data at all.

Troubleshooting

Popup controls are disabled
The tab is not an AP Classroom page, or it loaded before Nib. Refresh the page and reopen the popup.
Load unpacked reports a missing manifest
The selected folder is one level too high. Select the inner folder that contains manifest.json.
Some markers still show
Questions inside frames can load after Nib. Refresh the page, then turn Answer Hider on again.
Nib disappears after a restart
Unpacked extensions unload when their folder is moved, renamed, or deleted. Restore the folder and reload Nib from the extensions page.
