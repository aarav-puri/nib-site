Features

Retry any set. Honestly.

Every finished assignment is a set of questions you can use again. Nib makes them worth retrying.

Answers out of sight.

Markers and explanations, covered

Nib covers the green and red highlights and the answer explanations, so a finished assignment reads like a new one.

One switch.

In the popup or on the page

Turn hiding on or off from the Nib popup or the small panel on the page. Switch it off when you’re ready to check.

Setup guide

Set up in five minutes.

Nib installs from a folder on your computer. No coding needed.

Install the extension

1

Download Nib

Click Download above, or on GitHub choose Code, then Download ZIP. Unzip it somewhere permanent, like Documents. If you move the folder later, Nib stops working.

Or clone it with git:

git clone https://github.com/aarav-puri/nib
2

Open your extensions page

Type the address for your browser:

Chrome  chrome://extensions
Edge    edge://extensions
Brave   brave://extensions
3

Turn on Developer mode

Flip the switch in the top-right corner. A Load unpacked button appears.

4

Load unpacked

Click Load unpacked and pick the folder that contains manifest.json. ZIP downloads often add an extra folder level, so choose the inner one.

5

Pin Nib

Open the puzzle-piece menu and pin Nib to your toolbar.

Usage

1

Open a graded assignment

Go to any graded assignment or progress check on AP Classroom.

2

Turn on Answer Hider

Click Nib in your toolbar and turn on Answer Hider. The same switch appears in a small panel on the page.

3

Work the set again

Answer each question with the markers covered. Switch hiding off to check your work.
